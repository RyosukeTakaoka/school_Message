# 実機での確認手順（Phase 12）

iPad 2 台（ユーザ A / ユーザ B、**別々の iCloud アカウント**）で実施します。

事前に [`SETUP.md`](SETUP.md) を完了させてください。

---

## Scenario A — 1 対 1

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | A で起動し、表示名「A」ユーザID `user_a` を登録 | チャット一覧が表示される |
| 2 | B でも同様に `user_b` を登録 | |
| 3 | A: ツールバーの人型アイコン → 検索欄に `user_b` | B が結果に出る |
| 4 | A: 「追加」 | 友達一覧に B が入る |
| 5 | A: 友達一覧の B をタップ | シートが閉じ、右ペインに B とのチャットが開く |
| 6 | A: 「明日の集合何時？」と入力して送信 | すぐ吹き出しが出る。下に「送信中…」→ 時刻に変わる |
| 7 | B: アプリを前面に | 一覧に A が現れ、未読 ① が付く |
| 8 | B: A のチャットを開く | メッセージが読める。未読バッジが消える |

**確認ポイント**: 6 で送信ボタンを押した瞬間に入力欄が空になり、
吹き出しが出ること（アップロード完了を待たない）。

## Scenario B — 写真

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | A: 入力欄左の写真アイコン → 写真を選ぶ | 入力欄の上にプレビューが出る |
| 2 | A: 送信 | 吹き出しに写真が出る。半透明の覆いと進捗表示 |
| 3 | | アップロード完了で覆いが消える |
| 4 | B: チャットを開く | 写真が表示される（先にサムネイル） |
| 5 | B: 写真をタップ | 全画面で拡大表示。ピンチとダブルタップで拡大縮小 |
| 6 | B: 右上の × | チャットに戻る |

**確認ポイント**:
- 大きな写真（4000px 以上）を送っても数秒で完了すること（長辺 1600px に圧縮している）
- CloudKit Console で該当レコードの `mediaAsset` を見て、**画像として開けない**こと（暗号化されている）

## Scenario C — 動画

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | A: 写真アイコン → 動画を選ぶ | プレビューにサムネイルと再生マークが出る |
| 2 | A: 送信 | 再エンコードのあとアップロードが始まる |
| 3 | B: チャットを開く | サムネイルと再生時間が出る |
| 4 | B: タップ | ダウンロード中はぼかしたサムネイル + 進捗 |
| 5 | | ダウンロード完了で全画面再生が始まる |

- 圧縮後のサイズが 25MB を超えると「ファイルが大きすぎます」と出ること

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | A: ツールバーの人型 3 つのアイコン | グループ作成画面 |
| 2 | A: 画像を選び、名前「2年A組」を入力 | |

## Scenario E — 未読と通知

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | A: アプリを閉じる（ホーム画面へ） | |
| 2 | B: A にメッセージを 3 通送る | |
| 3 | A の iPad | 通知が届く（「B さんからメッセージが届きました」または本文入り） |
| 4 | A: アプリを開く | 一覧に未読 ③ |
| 5 | A: チャットを開く | メッセージが表示され、未読が消える |
| 6 | B: さらに 1 通送る | A のチャット画面にすぐ現れる。未読は付かない |
| 7 | A: アプリを閉じてから開き直す | 未読は 0 のまま（既読位置がサーバに保存されている） |

**確認ポイント**:
- 3 でアプリが起こされた場合は本文入りの通知になる
- プロフィール → 「通知に本文を表示」をオフにすると、本文が「新しいメッセージ」になる

## Scenario H — 規約への同意

**このシナリオは `AppConstants.Legal.requiresConsent = true` にしたときだけ
確認してください。** 既定値の `false` では同意画面自体が出ません
（プロフィール画面の「規約」から読めることだけ確認できれば十分です）。

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | アプリを新規インストールして起動 | 同意画面が出る。要点 4 つと、規約・ポリシーへのボタンが並ぶ |
| 2 | 「利用規約」をタップ | 全文が開き、最後まで読める。閉じると同意画面に戻る |
| 3 | 同意せずにアプリを終了 → 再起動 | もう一度同意画面が出る（先へ進めない） |
| 4 | スイッチをオンにして「同意してはじめる」 | プロフィール登録（または iCloud の案内）へ進む |
| 5 | 一度アプリを終了 → 再起動 | 同意画面は出ず、そのまま使える |
| 6 | プロフィール → 「規約」 | 利用規約・プライバシーポリシーを読み返せる |
| 7 | `ConsentStore.currentVersion` を変更して再ビルド | 「規約が更新されました」と表示され、再同意を求められる |

**確認ポイント**:
- 同意前は iCloud への接続が始まらない（同意画面で「iCloud にサインインしていません」等が出ない）
- 文字を最大サイズにしても文章が読める（Dynamic Type）

## Scenario F — 既読

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | A: B とのチャットでメッセージを送る | 吹き出しの下は時刻のみ（まだ既読なし） |
| 2 | B: そのチャットを開く | |
| 3 | A の画面（開いたまま） | 数秒以内に時刻の左へ「既読」が付く |
| 4 | グループで A が送信 → 2 人が開く | A の画面に「既読 2」と人数が出る |

**確認ポイント**:
- 相手が読んでいない間は何も出ない（「未読」とは表示しない）
- 自分が受け取ったメッセージには既読表示は出ない（出るのは自分の送信だけ）

## Scenario I — 送信取り消し

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | A: メッセージを送る | B に届く |
| 2 | A: 自分の吹き出しを長押し | 「送信を取り消す」が出る（相手の吹き出しには出ない） |
| 3 | 選ぶ | 「相手の画面には残ります」という確認が出る |
| 4 | 実行 | A の画面が破線枠の「送信を取り消しました」に変わる |
| 5 | B の画面（開いたまま） | 12 秒以内に同じ表示に変わる |
| 6 | 写真を送って取り消す | 画像が消え、B が既にダウンロード済みでも端末内のキャッシュごと消える |
| 7 | CloudKit Dashboard で該当レコードを見る | `mediaAsset` が空、`payload` が短い暗号文に変わっている |
| 8 | 取り消したメッセージを長押し | メニューが出ない（返信もコピーもできない） |
| 9 | 一覧画面 | 最後のメッセージが「送信を取り消しました」になる |
| 10 | 24 時間以上前のメッセージを長押し | 「送信を取り消す」が出ない |

**確認ポイント**:
- 相手の吹き出しを長押ししても「送信を取り消す」は出ない（他人のメッセージは消せない）
- 送信中（まだ届いていない）メッセージは、取り消しではなく従来どおり「取り消す」でキューから消える

## Scenario G — 返信（引用）

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | 吹き出しを長押し | 「返信」「コピー」のメニューが出る |
| 2 | 「返信」を選ぶ | 入力欄の上に引用が出て、キーボードが開く |
| 3 | 文字を入れて送信 | 吹き出しの上に引用が付いた状態で送られる |
| 4 | 相手の端末 | 同じ引用付きで表示される |
| 5 | 引用部分をタップ | 元メッセージまでスクロールし、一瞬ハイライトされる |
| 6 | 引用の × を押す | 返信をやめて通常の送信に戻る |

**確認ポイント**:
- 引用は暗号化ペイロードに入るので、CloudKit Dashboard 側の作業は不要
- 元メッセージがまだ読み込まれていない古い履歴のときは、5 で案内の帯が出る

## エラー処理の確認

要件 14 に対応する確認です。**必ず実施してください。**

| # | 状況の作り方 | 期待する挙動 |
|---|---|---|
| 1 | 機内モードにして送信 | 吹き出しは「送信中…」。上部に「オフライン」帯 |
| 2 | 機内モードを解除 | 自動で送信され、時刻表示に変わる |
| 3 | 機内モードのまま何度も送信 | すべてキューに積まれ、復帰後に順番どおり送られる |
| 4 | 機内モードで写真を送り、アプリを強制終了 → 再起動 | 送信待ちが残っており、オンラインになると送られる |
| 5 | 動画のアップロード中にアプリを強制終了 → 再起動 | 同上。圧縮済みファイルが残っているので最初からやり直しにならない |
| 6 | 「再送信」を押す | 試行回数がリセットされ、すぐ再送される |
| 7 | 「取り消す」を押す | 吹き出しが消え、ローカルファイルも削除される |
| 8 | 電波の悪い場所で長時間 | 4 回の再送後に「送信できませんでした ［再送信］」が出る |
